### DQL(Data Query Language)
#### SELECT
- SELECT 기능 3가지 : 프로젝션(열 단위 추출), 셀렉션(행 단위 추출), 조인
```SQL
SELECT salary * 12 연봉, ' 사번 : ' || employee_id || q'[. TestText]' AS "사번 + TESTTEXT"
FROM HR.EMPLOYEES;
```
- SELECT 절에서 ' * 12 ' 같은 계산식 표현 가능
- ' AS " A B C " == ' A B C ' 별칭 지정 ( ' AS ' 키워드 생략 가능 )
- ` q'[]' ` == Oracle의 Q-quoted string 문법
- 문자열은 왼쪽 정렬, NUMBER 타입은 우측 정렬로 결과가 출력된다 ( SQL Developer 프로그램상 )
