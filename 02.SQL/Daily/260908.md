### PIVOT
- 행(세로) 데이터를, 열(가로) 데이터로 변경
- ' PIVOT({그룹 함수} FOR 컬럼명 IN {}) ' 형태로 작성
```SQL
SELECT *
FROM ( SELECT department_id dept_id /* 별칭 지정시, PIVOT() 내에서 별칭으로만 사용 가능 ( ' department_id ' 컬럼명 사용시 ERR 발생 ) */
        FROM HR.EMPLOYEES)
PIVOT ( COUNT(*) FOR dept_id IN(10 "10번 부서", 20, 30, 40, 50, 60, 70, 80, 90, 100, 110, NULL AS "부서가 없는 사원") ),
(SELECT COUNT(*) 총인원수 FROM HR.EMPLOYEES);


SELECT *
FROM (SELECT department_id dept_id, COUNT(*) cnt
        FROM HR.EMPLOYEES
        GROUP BY department_id)
PIVOT ( MAX(cnt) FOR dept_id IN(10 "10번 부서", 20, 30, 40, 50, 60, 70, 80, 90, 100, 110, NULL AS "부서가 없는 사원") ),
(SELECT COUNT(*) 총인원수 FROM HR.EMPLOYEES);
```

### UNPIVOT
- 열(가로) 데이터를, 행(세로) 데이터로 변경
- ' INCLUDE NULLS ' == NULL 값도 생략하지 않고, 출력
```SQL
SELECT *
FROM(
    SELECT *
    FROM (SELECT TO_CHAR(hire_date, 'yyyy') AS "year", TO_CHAR(hire_date, 'Q') Q, salary /* PIVOT() 에서 선택되지 않은 year == 세로축이 된다 */
            FROM HR.EMPLOYEES
            )
    PIVOT( SUM(salary) FOR Q IN ('1' AS "1분기", '2' AS "2분기", '3' "3분기", 4 "4분기") )
)
UNPIVOT INCLUDE NULLS ( 총급여액 FOR 분기 IN ("1분기", "2분기", "3분기", "4분기") ) /* INCLUDE NULLS == NULL 값도 생략없이 출력 */
ORDER BY 1 DESC, 2 DESC;
```

2008|3분기|(null)|

2008|1분기|46900|

### 쌍비교, 비쌍비교
```SQL
SELECT *
FROM HR.EMPLOYEES
WHERE (manager_id, department_id) IN ( SELECT manager_id, department_id /* 쌍비교 ( 한번에 추출한 ' manager_id ', ' department_id ' 두가지 조건이 동시에 만족하는지 ) */
                                        FROM HR.EMPLOYEES
                                        WHERE first_name = 'John' ); /* first_name == John 사원들이 가진 manager_id, department_id 쌍으로 추출*/


SELECT *
FROM HR.EMPLOYEES
WHERE manager_id IN( SELECT manager_id
                        FROM HR.EMPLOYEES
                        WHERE first_name = 'John') /* first_name == John 사원들이 가진 manager_id 추출*/
    AND /* 비쌍비교 ( 각각 추출한 ' manager_id ', ' department_id ' 만족하는지 ) */
        department_id IN (SELECT department_id
                            FROM HR.EMPLOYEES
                            WHERE first_name = 'John'); /* first_name == John 사원들이 가진 department_id 추출*/
```
| 하나의 행에, WHERE 절의 2가지 조건이 동시에 만족하는지
|manager_id|department_id|
|---:|---:|
108|100|
100|80|
123|50|
- 쌍비교는, 추출한 ' (manager_id, department_id) ' 동시에 만족하는 행들을 추출 (예를들면, 108-100, 100-80, 123-50) /* 1조건과 2조건이 동시에 만족하는 행 */
- 비쌍비교는, 추출한 ' manager_id ', ' department_id ' 각각 교차로 만족하는 행들을 추출 (예를들면, 100-100, 100-80, 100-50, . . . ) /* 1조건이면서 2조건이 만족하는, 모든 경우의 수들을 만족하는 행들 */
