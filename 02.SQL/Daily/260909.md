### 집합 연산자
- 집합 연산자를 사용하는, 두 문장의 SELECT 컬럼 개수가 동일해야 한다 ( 불일치시, ERR 발생 )
- 집합 연산자를 사용하는, 두 문장의 각 SELECT 컬럼 위치에 따라 매칭 ( SELECT 1번째 컬럼끼리, 2번째 컬럼끼리 . . . )
  - 매칭되는 컬럼들의, 데이터 타입이 호환되지 않을 경우 ERR 발생
- UNION, INTERSECT, MINUS 3가지 연산자는, 중복 제거 작업을 위하여 내부적으로 정렬 발생
  - ' UNION ALL ' == 내부적으로 정렬 발생하지 않는다
#### UNION, UNION ALL
- 합집합 개념
- ' UNION ALL ' == 중복을 포함한, 합집합 결과
```SQL
SELECT employee_id, job_id, salary
FROM HR.EMPLOYEES
UNION /* 중복을 제거한, 합집합 결과 */
SELECT employee_id, job_id, NULL /* 대응되는 컬럼이 없기에 NULL ( 없을시 ERR 발생 )*/
FROM HR.JOB_HISTORY
ORDER BY 3 DESC;
```
</br></br></br>


#### INTERSECT
- 교집합 개념
```SQL
SELECT employee_id, job_id
FROM HR.EMPLOYEES
INTERSECT /* 중복을 제거한, 교집합 결과 */
SELECT employee_id, job_id
FROM HR.JOB_HISTORY;
```

#### MINUS
- 차집합 개념
- 첫 문장에 있으며, 둘번 문장에 없는 컬럼 반환 ( 두 문장의 순서를 바꾸면, 결과도 달라진다 )
```SQL
SELECT employee_id
FROM HR.EMPLOYEES
MINUS /* 중복을 제외한, 차집합 */
SELECT employee_id
FROM HR.JOB_HISTORY; /* ' HR.JOB_HISTORY ' == 부서 이동 이력이 있는 사원들의, 이력 정보 테이블 */
```
> 부서 이동 이력이 없는 사원들의 정보 출력 예제 코드
