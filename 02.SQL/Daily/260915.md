### SEQUENCE
- ' CREATE SEQUENCE ' 시스템 권한 필요
- 자동으로, 일련 번호 생성
- ' MAX_VALUE ' == ' CURRVAL ' 상태에서, 추가로 ' NEXTVAL ' 사용 불가
  - INSERT 시도하여, 성공시 ' MAX_VALUE ' < ' CURRVAL ' 되어야 하는 경우, INSERT 불가 ERR
    - ' CURRVAL ' == ' SELECT * FROM ALL_SEQUENCES ' 수행시, ' LAST_NUMBER '
- ' START WITH ' 제외한, 다른 옵션들은 수정 가능
```SQL
CREATE SEQUENCE HR.ID_SEQ
START WITH 1 /* ' START WITH ' 미설정시, 기본값은 1 */
MAXVALUE 10 /* ' MAXVALUE ' 미설정시, 기본값은 10의 27승 */
INCREMENT BY 1 /* ' INCREMENT BY ' 미설정시, 기본값은 1 */
NOCYCLE /* 기본값 ' NOCYCLE ' */
NOCACHE; /* 기본값은 CACHE == 20 */


DROP SEQUENCE HR.ID_SEQ; /* 시퀀스 삭제 */
```

</br></br></br>
```SQL
INSERT INTO HR.EMP(id, name)
VALUES(ID_SEQ.NEXTVAL, /* ' NEXTVAL ' == 실제 컬럼이 아닌, 의사 열 ( 가상 컬럼 == pseudo COLUMN ) */
        'Taylor Winston');


SELECT ID_SEQ.CURRVAL
FROM DUAL; /* ' CURRVAL ' == 가상 컬럼 == 현재까지 사용한 마지막 번호 ( ' NEXTVAL ' 사용 이력이 없다면, 조회 불가 ERR ) */


COMMIT;
```
- ' NEXTVAL ' == ' SELECT * FROM ALL_SEQUENCES; ' 실행시, ' LAST_NUMBER ' 값 반환 ( 미리 만들어져 있지 않고, 사용시에 생성하여 반환 )

```SQL
SELECT ID_SEQ.NEXTVAL /* ' NEXTVAL ' 사용함으로 처리되어 CURRVAL + 1 증가 (' SELECT * FROM ALL_SEQUENCES ' 수행시, ' LAST_NUMBER ' + 1 증가 ) */
FROM DUAL;


COMMIT;
```
> ' NEXTVAL ' 사용하여 조회하는 경우에도, ' NEXTVAL ' 사용함으로 처리되는 예제 코드

```SQL
ALTER SEQUENCE ID_SEQ /* ' START WITH ' 제외한, 다른 옵션들은 수정 가능 */
MAXVALUE 5
INCREMENT BY 2;


INSERT INTO HR.EMP(id, name) /* INSERT 성공시, MAXVALUE 5 설정보다 큰 6 되어야 하기에 ERR */
VALUES(ID_SEQ.NEXTVAL,
        'Asher');
```
> MAXVALUE == 5 시퀀스 上 INSERT 성공시에,  ' CURRVAL ' ( ' SELECT * FROM ALL_SEQUENCES ' 수행시, ' LAST_NUMBER ' ) > MAXVALUE 되어야 하기에 ERR 발생하는 예제 코드
