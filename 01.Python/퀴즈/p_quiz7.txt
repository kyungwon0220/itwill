01. for 루프와 while 루프의 차이점은 무엇인가?

    # for 루프 예제
    for i in range(5):
        print(i)

    # while 루프 예제
    i = 0
    while i < 5:
        print(i)
        i += 1

    - a)  for  루프는 조건이 참일 때만 실행된다.
    - b)  while  루프는 조건이 거짓일 때만 실행된다.
    - c)  for  루프는 미리 정의된 반복 횟수를 가진다. 



02.  range()  함수는 어떻게 작동하는가?

    for i in range(2, 10, 2):  
        print(i)

    - a) 2부터 10까지의 모든 정수를 반환한다.
    - b) 2부터 10 미만의 모든 짝수를 반환한다.  
    - c) 2부터 10 미만의 모든 홀수를 반환한다.
    - d) 2부터 10까지의 모든 소수를 반환한다.



03.  for  루프 안에서  break  문을 사용하면 어떤 일이 발생하는가?

    for i in range(10):
        if i == 5:
            break
        print(i)

    - a) 반복문이 계속해서 실행된다.
    - b) 반복문이 처음부터 다시 시작된다.
    - c) 반복문이 5번 실행된 후 종료된다.   
    - d) 반복문이 10번 실행된 후 종료된다.


04.  continue  문은 무엇을 하는가?

    for i in range(10):
        if i % 2 == 0:
            continue
        print(i)
 
    - a) 현재 반복을 종료하고 다음 반복으로 건너뛴다.    
    - b) 반복문을 종료한다.
    - c) 반복문을 처음부터 다시 시작한다.
    - d) 현재 반복을 계속 진행한다.



05. 중첩된 루프란 무엇인가?
    for i in range(3):

    - a) 루프가 한 번만 실행된다.

    - c) 한 루프가 다른 루프 안에 포함되어 있는 경우를 말한다.    
    - d) 두 개의 독립적인 루프가 있다.
