[ SQLite TODO LIST 프로젝트 ]

# 프로젝트 개요

사용자가 해야 할 일을 등록하고 관리할 수 있는 콘솔 기반 TODO LIST 프로그램을 Python과 SQLite를 이용하여 구현한다.
프로그램은 별도의 서버나 외부 데이터베이스 없이 SQLite 데이터베이스 파일인 todo.db를 사용한다.

사용자는 다음 기능을 수행할 수 있다.

1. 할 일 추가
2. 할 일 조회
3. 할 일 수정
4. 할 일 삭제
5. 완료/미완료 변경
0. 프로그램 종료


# 데이터베이스 요구사항

DB_NAME = "todo.db"

## 테이블 구조

id	INTEGER	PRIMARY KEY AUTOINCREMENT	TODO 번호
title	TEXT	NOT NULL	할 일 내용
completed	INTEGER	DEFAULT 0	완료 여부

완료 상태
0 → 미완료
1 → 완료

sql = """
CREATE TABLE IF NOT EXISTS todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    completed INTEGER DEFAULT 0
)
"""


# 기능 요구사항

## 기능 1. 할 일 추가
사용자가 할 일을 입력하면 데이터베이스에 저장한다.

* 사용자에게 할 일을 입력받는다.
* 빈 문자열인지 검사한다.
* 빈 문자열이면 저장하지 않는다.
* 정상적인 내용이면 todos 테이블에 저장한다.
* 새로 등록되는 TODO의 상태는 미완료(0)로 설정한다.
* 저장 후 "할 일이 추가되었습니다."를 출력한다.


## 기능 2. 할 일 전체 조회
등록된 모든 TODO를 화면에 출력한다.

* todos 테이블의 모든 데이터를 조회한다.
* TODO 번호를 출력한다.
* TODO 내용을 출력한다.
* 완료 여부를 완료, 미완료로 표시한다.
* TODO 번호가 큰 순서대로 출력한다.
* 등록된 TODO가 없으면 안내 메시지를 출력한다.


## 기능 3. 할 일 수정
등록된 TODO의 내용을 수정한다.

* 현재 TODO 목록을 먼저 출력한다.
* 수정할 TODO 번호를 입력받는다.
* 해당 번호가 존재하는지 확인한다.
* 존재하지 않으면 오류 메시지를 출력한다.
* 존재하면 기존 TODO 내용을 출력한다.
* 새로운 내용을 입력받는다.
* 빈 내용이면 수정하지 않는다.
* 새로운 내용으로 데이터를 수정한다.
* 수정 후 완료 여부는 기존 상태를 유지한다.


## 기능 4. 할 일 삭제
등록된 TODO를 삭제한다.

* 현재 TODO 목록을 출력한다.
* 삭제할 TODO 번호를 입력받는다.
* 해당 TODO가 존재하는지 확인한다.
* 존재하지 않으면 삭제하지 않는다.
* 삭제할 내용을 사용자에게 보여준다.
* 삭제 여부를 다시 확인한다.
* 사용자가 y를 입력하면 삭제한다.
* y가 아니면 삭제를 취소한다.


## 기능 5. 완료/미완료 변경
TODO의 상태를 변경한다. 토글(toggle) 방식으로 구현

현재 상태가: 
    미완료 → 완료
    완료 → 미완료

* TODO 목록을 출력한다.
* 변경할 TODO 번호를 입력받는다.
* 해당 TODO의 현재 상태를 조회한다.
* 현재 상태가 0이면 1로 변경한다.
* 현재 상태가 1이면 0으로 변경한다.
* 변경 결과를 출력한다.
