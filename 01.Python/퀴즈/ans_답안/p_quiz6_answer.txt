03. 주어진 리스트 ['apple', 'banana', 'cherry']에서 문자열의 길이를 계산하여 
        새로운 리스트를 만드는 코드로 올바른 것은?
   
	결과 예시 :  [5, 6, 6]



답: 
# 주어진 리스트
fruits = ['apple', 'banana', 'cherry']
lengths = []

# 인덱스 초기화
i = 0
while i < len(fruits):
    lengths.append(len(fruits[i]))  # 문자열의 길이를 계산하여 추가
    i += 1  # 인덱스 증가

print(lengths)  # 결과 출력

[3, 5, 6, 9, 10, 12, 15, 18, 20, 21, 24, 25, 27, 30]




답 :
# 빈 리스트 초기화
multiples = []

# 인덱스 초기화
num = 1

# 1부터 30까지 반복
while num <= 30:
    if num % 3 == 0 or num % 5 == 0:  # 3이나 5의 배수인지 확인

    num += 1  # 다음 숫자로 증가

print(multiples)  # 결과 출력




05. 빈 리스트를 정의한 후 1부터 10까지의 수 중에서 3의 배수를 "Fizz"로 추가하고,  그렇지 않으면 숫자 그대로 리스트에 추가하는 코드를 작성하면?

최종 출력 형태 :
		[1, 2, 'Fizz', 4, 5, 'Fizz', 7, 8, 'Fizz', 10]



답: 
fizz_list = []
x = 1  # 초기 값 설정

while x <= 10:  # 1부터 10까지 반복
    if x % 3 == 0:  # x가 3의 배수인지 확인
        fizz_list.append("Fizz")  # 3의 배수일 경우 "Fizz" 추가
    else:
        fizz_list.append(x)  # 아니면 숫자 추가
    x += 1  # x 증가

print(fizz_list)  # 결과 출력


06. 주어진 리스트 
fruits = ['apple', 'banana', 'cherry', 'kiwi', 'grape', 'orange', 'peach', 'mango']
에서 각 과일의 첫 글자를 대문자로 바꾸고, 
그 길이가 5 이하인 과일 이름만 포함하는 리스트를 만드는 코드를 작성하여라. 
    (upper(), len(), lower())

# 리스트 정의 
fruits = ['apple', 'banana', 'cherry', 'kiwi', 'grape', 'orange', 'peach', 'mango']
capitalized_fruits = []

# 최종 출력 결과 : ['Apple', 'Kiwi', 'Grape', 'Peach', 'Mango']



답: 
fruits = ['apple', 'banana', 'cherry', 'kiwi', 'grape', 'orange', 'peach', 'mango']
capitalized_fruits = []
i = 0  # 인덱스 초기화

while i < len(fruits):  # fruits 리스트의 길이만큼 반복
    fruit = fruits[i]  # 현재 과일 이름 가져오기
    if len(fruit) <= 5:  # 과일 이름 길이 확인
        capitalized_fruits.append(fruit[0].upper() + fruit[1:].lower())  # 대문자 및 소문자 변환
    i += 1  # 인덱스 증가

print(capitalized_fruits)  # 결과 출력

 exit을 입력하면 입력 종료 후 저장된 딕셔너리를 출력하도록 프로그래밍하시오 


저장할 단어를 입력하세요 (종료: exit): apple
apple의 뜻을 입력하세요: 사과
저장할 단어를 입력하세요 (종료: exit): start
start의 뜻을 입력하세요: 시작
저장할 단어를 입력하세요 (종료: exit): milk
milk의 뜻을 입력하세요: 우유
저장할 단어를 입력하세요 (종료: exit): exit


 저장된 단어 목록

답 :
word_dict = {}

while True:
    word = input("저장할 단어를 입력하세요 (종료: exit): ")
    
    if word.lower() == "exit":
        break
    
    meaning = input(f"{word}의 뜻을 입력하세요: ")
    word_dict[word] = meaning  # 단어 저장

print("\n\n 저장된 단어 목록")
print(word_dict)



12.  사용자가 제품 이름과 재고 수량을 입력하면 딕셔너리에 저장하고,
exit을 입력하면 종료 후 모든 재고를 출력하도록 프로그래밍하여라. 
- 딕셔너리 저장시 제품 이름은 키, 재고 수량은 값
- 제품이름이 기존 제품이면 재고량 추가 

결과 예시)

추가할 제품명을 입력하세요 (종료: exit): 밀가루
밀가루의 재고 수량을 입력하세요: 10
추가할 제품명을 입력하세요 (종료: exit): 고추장
고추장의 재고 수량을 입력하세요: 5
추가할 제품명을 입력하세요 (종료: exit): 상추
상추의 재고 수량을 입력하세요: 10
추가할 제품명을 입력하세요 (종료: exit): 밀가루
밀가루의 재고 수량을 입력하세요: 5
추가할 제품명을 입력하세요 (종료: exit): 설탕
설탕의 재고 수량을 입력하세요: 10
추가할 제품명을 입력하세요 (종료: exit): exit

 제품 재고
{'밀가루': 15, '고추장': 5, '상추': 10, '설탕': 10}




답:
inventory = {}

while True:
    product = input("추가할 제품명을 입력하세요 (종료: exit): ")
    
    if product.lower() == "exit":
        break
    
    quantity = int(input(f"{product}의 재고 수량을 입력하세요: "))
    
    if product in inventory:
        inventory[product] += quantity  # 기존 제품이면 수량 추가
    else:
        inventory[product] = quantity  # 새로운 제품이면 추가

print("\n 제품 재고")
print(inventory)
