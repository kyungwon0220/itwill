01. 다음 SQL을 실행한 결과로 올바른 것은?

```sql
SELECT name, age
FROM students
WHERE age >= 20;
```

A) 모든 학생의 이름과 나이를 조회한다.
B) 20세 이상 학생의 이름과 나이를 조회한다.
C) 20세 미만 학생의 이름과 나이를 조회한다.
D) 나이가 정확히 20세인 학생만 조회한다.

**정답: B**

해설: `WHERE age >= 20`은 나이가 **20 이상**인 행만 선택한다.

### 02. 다음 SQL을 실행했을 때 어떤 데이터가 수정되는가?

```sql
UPDATE students
SET age = age + 1
WHERE id = 3;
```

A) 모든 학생의 나이가 1 증가한다.
B) id가 3인 학생의 나이가 1 증가한다.
C) id가 3인 학생의 나이가 3으로 변경된다.
D) id가 3인 학생이 삭제된다.

**정답: B**

해설: `WHERE id = 3`으로 대상을 제한하고, `age = age + 1`로 기존 나이에 1을 더한다.

### 03. 다음 SQL의 실행 결과로 올바른 것은?

```sql
DELETE FROM students
WHERE age < 20;
```

A) 20세 미만 학생을 삭제한다.
B) 20세 이상 학생을 삭제한다.
C) 모든 학생을 삭제한다.
D) 나이 정보를 삭제한다.

**정답: A**

해설: `< 20` 조건을 만족하는 행만 삭제한다.

### 04. 다음 SQL의 문제점은 무엇인가?

```sql
UPDATE students
SET grade = 3;
```

A) SET을 사용할 수 없다.
B) UPDATE에서는 숫자를 사용할 수 없다.
C) WHERE가 없기 때문에 모든 학생의 grade가 3으로 변경된다.
D) grade 컬럼은 반드시 문자열이어야 한다.

**정답: C**

해설: `WHERE`가 없으면 테이블의 **모든 행**이 UPDATE 대상이 된다.

### 05. 다음 SQL에서 조회되는 컬럼은 무엇인가?

```sql
SELECT name, age
FROM students
WHERE grade = 2;
```

A) name만 조회
B) age만 조회
C) name과 age 조회
D) 모든 컬럼 조회

**정답: C**

해설: `SELECT name, age`이므로 두 컬럼만 조회한다.

### 06. 다음 SQL의 결과를 가장 정확하게 설명한 것은?

```sql
SELECT *
FROM students
WHERE age BETWEEN 20 AND 25;
```

A) 20세와 25세를 제외한 학생
B) 20세 이상 25세 이하의 학생
C) 20세 미만 또는 25세 초과 학생
D) 정확히 20세와 25세인 학생

**정답: B**

해설: SQLite의 `BETWEEN 20 AND 25`는 **20과 25를 포함**하는 범위이다.

### 07. 다음 SQL을 실행하면 어떤 순서로 결과가 정렬되는가?

```sql
SELECT *
FROM students
ORDER BY age DESC;
```

A) 나이가 적은 순서
B) 나이가 많은 순서
C) 이름순
D) 입력된 순서

**정답: B**

해설: `DESC`는 내림차순이므로 숫자인 나이는 **큰 값 → 작은 값** 순서로 정렬된다.

### 08. 다음 SQL의 결과로 올바른 것은?

```sql
SELECT *
FROM students
WHERE age >= 20
ORDER BY age ASC;
```

A) 20세 이상 학생을 나이 많은 순서로 조회
B) 20세 이상 학생을 나이 적은 순서로 조회
C) 20세 미만 학생을 나이 적은 순서로 조회
D) 모든 학생을 이름순으로 조회

**정답: B**

해설: `WHERE`는 20세 이상으로 필터링하고 `ORDER BY age ASC`는 나이 오름차순으로 정렬한다.

### 09. 다음 중 `students` 테이블에서 이름이 '홍길동'인 학생의 나이를 25로 변경하는 올바른 SQL은?

A)

```sql
UPDATE students
SET age = 25
WHERE name = '홍길동';
```

B)

```sql
UPDATE students
WHERE name = '홍길동'
SET age = 25;
```

C)

```sql
UPDATE students
SET name = 25
WHERE age = '홍길동';
```

D)

```sql
INSERT INTO students
SET age = 25
WHERE name = '홍길동';
```

**정답: A**

해설: `UPDATE → SET → WHERE` 순서로 작성한다.

### 10. 다음 SQL을 실행한 결과로 올바른 것은?

```sql
DELETE FROM students
WHERE id = 10;
```

A) id가 10인 행을 삭제한다.
B) id가 10인 컬럼을 삭제한다.
C) students 테이블 자체를 삭제한다.
D) 모든 행을 삭제한다.

**정답: A**

해설: `DELETE FROM`은 행을 삭제하며 `WHERE id = 10`으로 삭제 대상을 지정한다.

### 11. 다음 SQL을 실행했을 때 `students` 테이블 자체가 삭제되는가?

```sql
DELETE FROM students;
```

A) 테이블과 모든 데이터가 삭제된다.
B) 모든 데이터가 삭제되지만 테이블 구조는 남는다.
C) 첫 번째 데이터만 삭제된다.
D) 아무런 변화가 없다.

**정답: B**

해설: `DELETE FROM`은 **행을 삭제**한다. 테이블 자체를 삭제하려면 `DROP TABLE`을 사용한다.

### 12. 다음 중 학생 데이터를 추가하는 SQL로 올바른 것은?

```text
id = 5
name = '김민수'
age = 22
```

A)

```sql
INSERT students VALUES (5, '김민수', 22);
```

B)

```sql
INSERT INTO students VALUES (5, '김민수', 22);
```

C)

```sql
ADD INTO students VALUES (5, '김민수', 22);
```

D)

```sql
UPDATE students VALUES (5, '김민수', 22);
```

### 13. 다음 SQL의 실행 결과는?

```sql
SELECT name
FROM students
WHERE age > 20;
```

A) 20세인 학생의 이름
B) 20세 이상 학생의 이름
C) 20세 초과 학생의 이름
D) 모든 학생의 이름

**정답: C**

해설: `>`는 해당 숫자를 **포함하지 않는다**. 따라서 20보다 큰 학생만 조회된다.

### 14. 다음 SQL의 실행 결과로 올바른 것은?

```sql
SELECT *
FROM students
WHERE grade = 3 AND age >= 20;
```

A) 3학년 또는 20세 이상인 학생
B) 3학년이면서 20세 이상인 학생
C) 3학년이면서 20세 미만인 학생
D) 모든 학생

**정답: B**

해설: `AND`는 두 조건을 **모두 만족**해야 한다.

### 15. 다음 SQL의 실행 결과로 올바른 것은?

```sql
SELECT *
FROM students
WHERE grade = 1 OR grade = 3;
```

A) 1학년만 조회
B) 3학년만 조회
C) 1학년과 3학년을 조회
D) 2학년만 조회

**정답: C**

해설: `OR`는 두 조건 중 **하나 이상 만족**하면 조회 대상이 된다.

### 16. 다음 SQL의 실행 결과는?

```sql
UPDATE students
SET age = age + 2
WHERE grade = 1;
```

A) 1학년 학생의 나이를 2로 변경
B) 1학년 학생의 나이를 기존 값에서 2 증가
C) 모든 학생의 나이를 2 증가
D) 2학년 학생의 나이를 1 증가

**정답: B**

해설: `age = age + 2`는 기존 `age` 값에 2를 더한다. `WHERE grade = 1`이므로 1학년만 수정된다.

### 17. 다음 SQL을 실행한 후 어떤 데이터가 삭제되는가?

```sql
DELETE FROM students
WHERE grade = 3 AND age < 20;
```

A) 모든 3학년 학생
B) 20세 미만인 모든 학생
C) 3학년이면서 20세 미만인 학생
D) 3학년이거나 20세 미만인 학생

**정답: C**

해설: `AND`이므로 **3학년 조건과 20세 미만 조건을 모두 만족**해야 한다.

### 18. 다음 SQL의 실행 결과로 올바른 것은?

```sql
SELECT name, age
FROM students
ORDER BY age DESC
LIMIT 3;
```

A) 나이가 가장 적은 3명의 이름과 나이
B) 나이가 가장 많은 3명의 이름과 나이
C) 모든 학생의 이름과 나이
D) 3세 이상 학생의 이름과 나이

**정답: B**

해설: `DESC`로 나이가 많은 순서로 정렬한 후 `LIMIT 3`으로 **3개 행만 조회**한다.

### 19. 다음과 같은 데이터가 있다고 가정하겠습니다.

```text
id | name   | age
---+--------+----
1  | 홍길동 | 20
2  | 김철수 | 25
3  | 이영희 | 22
```

다음 SQL 실행 후 결과는?

```sql
UPDATE students
SET age = age + 1
WHERE age >= 22;
```

A) 홍길동 21, 김철수 26, 이영희 23
B) 홍길동 20, 김철수 26, 이영희 23
C) 홍길동 21, 김철수 25, 이영희 22
D) 모든 학생의 나이가 1 증가

**정답: B**

해설: `age >= 22`인 김철수와 이영희만 수정된다. 따라서 25→26, 22→23이 된다.

### 20. 다음과 같은 데이터가 있다고 가정합니다.

```text
id | name   | age | grade
---+--------+-----+------
1  | 홍길동 | 19  | 1
2  | 김철수 | 21  | 2
3  | 이영희 | 20  | 3
4  | 박민수 | 23  | 3
```

다음 SQL 실행 후 남는 데이터는 무엇인가요?

```sql
DELETE FROM students
WHERE grade = 3 AND age >= 21;
```

A) 홍길동, 김철수
B) 이영희, 박민수
C) 홍길동, 이영희
D) 김철수, 이영희

**정답: A**

해설: `grade = 3 AND age >= 21`을 동시에 만족하는 학생은 **박민수**뿐이다. 따라서 박민수가 삭제되고 홍길동, 김철수, 이영희가 남는다.

**주의:** 위 선택지에는 이 부분의 정확한 결과를 반영하면 **A가 아니라 `홍길동, 김철수, 이영희`가 정답**이어야 합니다. 따라서 문제의 선택지를 수정하면 다음과 같습니다.

A) 홍길동, 김철수, 이영희
B) 이영희, 박민수
C) 홍길동, 이영희
D) 김철수, 이영희

**최종 정답: A**

해설: 3학년이면서 21세 이상인 **박민수만 삭제**되므로 나머지 세 명이 남습니다.
