문제14:  원화를 입력받아 달러로 변환하도록 프로그래밍 하여라
- int() 나눗셈 결과의 소수점을 버리는 방식을 이용한다. 

출력 예시 >>

환전할 원화 금액을 입력하세요 (예: 156000) : 156000
---------------------------------------
입력한 원화 금액 : 156000 원
오늘의 달러 환율 : 1560 원
---------------------------------------
환전 결과 (USD)  : 100 달러입니다.





# 프로그래밍 예시 

won_input = input("환전할 원화 금액을 입력하세요 (예: 156000) : ")

# 요청하신 최신 환율 정보 1560원을 정수 형태로 변수 지정
exchange_rate = 1560

# 문자열로 입력된 원화 금액을 계산이 가능한 정수형(int)으로 변환
won_money = int(won_input)


usd_money = int(won_money / exchange_rate)

print("---------------------------------------")
print("입력한 원화 금액 :", won_money, "원")
print("오늘의 달러 환율 :", exchange_rate, "원")
print("---------------------------------------")
print("환전 결과 (USD)  :", usd_money, "달러입니다.")





문제 15. 총 결제금액과 함께 먹은 총 인원수를 입력받으면 1인당 보낼 금액이 자동으로 계산되는 더치페이(N분의 1) 금액 계산기를 파이썬으로 프로그래밍하여라. 
- int() 나눗셈 결과의 소수점을 버리는 방식을 이용한다. 

출력예시 >>

총 결제 금액을 입력하세요 (원): 45000
함께 먹은 총 인원수를 입력하세요 (명): 3
---------------------------------------
총 결제 금액 : 45000 원
참여 인원수  : 3 명
---------------------------------------
1인당 보낼 금액 : 15000 원입니다.




프로그래밍 예시 >>

# input()을 통해 총 결제 금액과 인원수를 문자열 형태로 입력받는다.
total_price_input = input("총 결제 금액을 입력하세요 (원): ")
people_count_input = input("함께 먹은 총 인원수를 입력하세요 (명): ")

# 입력받은 문자열 데이터를 산술 연산이 가능하도록 정수형(int)으로 변환한다.
total_price = int(total_price_input)
people_count = int(people_count_input)

# 총 금액을 인원수로 나누어 1인당 내야 할 금액을 계산

dutch_price = int(total_price / people_count)

print("---------------------------------------")
print("총 결제 금액 :", total_price, "원")
print("참여 인원수  :", people_count, "명")
print("---------------------------------------")


print("1인당 보낼 금액 :", dutch_price, "원입니다.")







문제16: 
사용자가 초를 입력하면 이를 시, 분, 초로 변환하여 출력하는 코드를 프로그래밍 하여라

출력예시 >>

	1시간 = 3600초
	1분 = 60초
	입력된 초를 3600으로 나누어 시간을 구하고, 나머지로 분과 초를 계산
	(% 연산자 이용) 


	결과 :
		초 단위의 시간을 입력하세요:   250000

		250000 초는 69시간 26분 40초입니다.



프로그래밍 예시 >>
# 사용자로부터 초 입력 받기
total_seconds = int(input("초 단위의 시간을 입력하세요: "))

# 시 계산
hours = total_seconds // 3600

# 분 계산
minutes = (total_seconds % 3600) // 60

# 초 계산
seconds = total_seconds % 60

# 결과 출력
print(total_seconds, '초는', hours, '시간', minutes ,'분' , seconds, "초입니다.")





문제17: 

사용자가 지불한 금액과 구매한 금액을 입력하면, 이를 기반으로 잔돈을 계산하여 출력하는 코드를 작성하여라.

- 잔돈은 500원, 100원, 50원, 10원, 1원으로 나누어 계산한다. 
- 각 동전의 개수를 출력하여야 한다. 


출력예시 >>
		지불한 금액을 입력하세요: 30000
		물품 가격을 입력하세요: 25789

		결과 :

		잔돈은 다음과 같습니다:
		500원:  8 개
		100원:  2 개
		50원:  0 개
		10원:  1 개
		1원:  1 개



프로그래밍 예시 >>
# 사용자로부터 지불한 금액과 물품 가격 입력 받기
paid_amount = int(input("지불한 금액을 입력하세요: "))
item_price = int(input("물품 가격을 입력하세요: "))

# 잔돈 계산
change = paid_amount - item_price

# 동전 단위로 잔돈 계산
five_hundred = change // 500
change = change % 500

hundred = change // 100
change = change % 100

fifty = change // 50
change = change % 50

ten = change // 10
change = change % 10

one = change

# 결과 출력
print("잔돈은 다음과 같습니다:")
print("500원: ", five_hundred ,"개")
print("100원: ", hundred ,"개")
print("50원: ", fifty ,"개")
print("10원: ", ten ,"개")
print("1원: ", one ,"개")
