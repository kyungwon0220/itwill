3. 복제 DB 內 User 생성
4. Roll Grant
5. 복제 DB, RMAN 접속
   ```  
   create catalog;
   ```
6. Target DB Instance Session 上 Catalog DB 접속
   ```
   rman target / catalog rc_user/oracle@rcdb;

   register database;
   ```

### Backup Script
```
create script incr_0_backup {
                                backup incremental level 0 database include current controlfile;
                                sql 'alter system archive log current';
}

replace script incr_0_backup {
    backup incremental level 0 database include current controlfile;
    alter system archive log current;
}
```
> Target DB 內 Catalog DB RMAN 접속하여 Script 생성 및 수정 예제 코드

</br></br></br>

```
resync catalog;

list script names;

print script incr_0_backup;
```
- Catalog DB 內 ' select * from rc_stored_script; ', ' select * from rc_stored_script_line; ' 직접 조회도 가능
</br></br></br>

```
run {execute script incr_0_backup;}
```
> Backup Script 실행 예제 코드

```
delete script incr_0_backup;
```
