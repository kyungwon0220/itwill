#### Private SQL Area == Cursor == SQL 실행 영역에서, SELECT 처리 단계
![](./mdIMG/ServerProcessRole.jpg)
> https://docs.oracle.com/en/database/oracle/oracle-database/19/cncpt/sql.html#GUID-1B95E60C-99C5-446D-9C6B-5D16EFE59ACF:~:text=the%20general%20stages%3A-,Figure%208%2D3%20Stages%20of%20SQL%20Processing,-Description%20of%20%22Figure
1. User Process, SQL 문장을 던진다
2. Server Process, CURSOR 메모리 할당받고
3. User Process 던져준 SQL 문장을 받아서, 이미지상의 ' Parsing ' 작업
- Syntax Check ( 문법 체크 ) == ' SELECT ', ' FROM ', ' WHERE ', ' * ', ' = ' 등의 문법을 옳게 작성했는지 Check
- Semantic Check ( 의미 분석 체크 ) == ' Data Dictionary ' 정보로 테이블의 소유자명, 객체 타입, SQL 문장 실행 권한 등을 Check
  - ![](./mdIMG/DataDictionaryInfo.jpg)
    - ' Data Dictionary ' 정보는 ' Data Files ' 內 존재
      - 이를 Semantic Check (의미 분석 체크 ) 할때마다, 디스크의 ' Data Files ' I/O 부담으로, [Database Buffer Cache](SGA.md#database-buffer-cache) 메모리에 Block 단위로 올려두고, 더욱 빠른 사용을 위해서 [Shared Pool 內 Data dictionary Cache](SGA.md#data-dictionary-cache) 공간에 ROW 단위로 올려두고 사용한다
        - 하여, Semantic Check (의미 분석 체크 ) 시도시, ' Data dictionary Cache ' > ' Database Buffer Cache ' > 디스크 순으로 탐색한다 ( 디스크에서 발견시, 역순으로 캐시에 올린 後 Check )
  - ```SQL
    SELECT *
    FROM SYS.USER$ /* Oracle 내부 데이터 딕셔너리 테이블 ( 직접 INSERT / UPDATE / DELETE / 구조 변경은 하지 않는 것이 원칙 ) */
    WHERE USERNAME = 'HR' /* ' HR ' 유저가 존재하는지 체크 */


    SELECT *
    FROM SYS.OBJ$ /* 실제 DATA 저장된 테이블로서, 일반 유저는 조회 불가 ( 테이블, 인덱스, 뷰, 프로시저 등 모든 객체의 기본 메타 정보가 마스터격 )*/
    WHERE OWNER = 'HR' AND OBJECT_NAME = 'EMPLOYEES'; /* ' HR ' 소유한, 'EMPLOYEES ' 객체 정보 조회 */



    SELECT *
    FROM SYS.TAB$; /* 객체 타입이 테이블일 경우, 테이블의 실제 정보가 저장된 TABLE 정보 조회 ( 테이블의 고유 특성(저장 공간 설정 등) )*/


    SELECT *
    FROM SYS.SEG$; /* 어느 테이블 스페이스의, 어느 Data 파일에 저장되어 있는지 조회 */


    SELECT *
    FROM SYS.COL$; /* 테이블에 속한 컬럼들의, 메타 정보(데이터 타입, 길이 등)가 저장된 원본 딕셔너리 TABLE */


    SELECT *
    FROM SYS.OBJAUTH$; /* 객체 권한에 대한 정보 조회 */
    ```
- Soft Parsing
  - 동일한 SQL 문장이 Shared Pool 메모리 內 라이브러리 캐시 영역에 있는지 조회하여, 있다면 ' 실행 계획 ' 공유 ( 재활용 )
    - |동일한 SQL 조건|
      |---|
      |대, 소문자와 공백, TAB, ENTER KEY|
      |소유자.TABLE (VIEW) 객체명|
      |힌트 ( /\*+ \*/), 주석 (--, /* */)|
      |상수값, 리터럴 값 일치|
- Hard Parsing
  - 동일한 SQL 문장이 없다면, 새로 메모리 할당받아서 옵티마이저라는 프로그램이 딕셔너리 TABLE 內 Table, Column 통계 정보로 ' 실행 계획 ' 생성
