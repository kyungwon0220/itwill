## 261016fri
### [Control File](261007.md#control-file) 이관
- Control 파일은, 운영중 이관 불가
1. 이관 前 [초기 파라미터 파일](InitializationParameterFileAndParameter.md#initial-parameter-file) Check
   ```SQL
   SHOW PARAMETER SPFILE;
   ```
2. ' control_files ' Parameter ( Static Parameter ) 수정
   ```SQL
   ALTER SYSTEM SET control_files='/home/oracle/Documents/insadata/control01.ctl' SCOPE=SPFILE;

   
   SELECT NAME FROM v$controlfile;
   ```
   - [Text Parameter File](InitializationParameterFileAndParameter.md#text-parameter-file) 경우, DB Down 後 편집기로 직접 수정 필요
3. DB 정상 종료 ( shutdown immediate; )
4. OS 內 물리적 File 이동
   ```CMD
   mv -v /u01/app/oracle/oradata/ORA19C/control01.ctl /home/oracle/Documents/
   mv -v /u01/app/oracle/oradata/ORA19C/redo01.log /home/oracle/Documents/
   mv -v /u01/app/oracle/oradata/ORA19C/redo02.log /home/oracle/Documents/
   ```
5. ```
   startup mount

   
   SELECT INSTANCE_NAME, STATUS FROM v$instance;
   ```
   > ' STATUS ' == ' MOUNTED ' == mount 시점까지 DB Open
6. Control File 內 Redo Log File 경로 정보 수정
   ```SQL
   ALTER DATABASE RENAME FILE '/u01/app/oracle/oradata/ORA19C/redo01.log' TO '/home/oracle/Documents/redo01.log';
   ALTER DATABASE RENAME FILE '/u01/app/oracle/oradata/ORA19C/redo02.log' TO '/home/oracle/Documents/redo02.log';


   SELECT MEMBER FROM v$logfile;
   ```
7. DB Open ( ALTER DATABASE OPEN; )

### Undo
- 8i Version 까지는, ' 롤백 ' 이라는 공간 관리였었고, 9i Version 부터 ' Undo ' 신규 용어 ( Oracle Auto 관리 )
  - ```SQL
    SHOW PARAMETER undo_management; /* VALUE AUTO == Oracle Auto 관리 */
    ```
    > 수동 관리로 변경시, 이점이 전혀 없기에 Auto 관리 고정 권장
- DML 작업시, 이전값 저장 공간
  - Transaction 끝나기 전까지, 이전값 보존 필수
- Instance Failure 발생시, Transaction 복구에 필요
- DB 운영중, 하나의 Undo 스페이스만 사용
- ```SQL
  SELECT n.usn, n.name, s.extents, s.rssize, s.xacts, s.status
  FROM v$rollname n, v$rollstat s
  WHERE n.usn = s.usn;
  ```
  |USN|NAME|EXTENTS|RESIZE|XACTS|STATUS|
  ---:|:---|---:|---:|---:|:---|
  0|SYSTEM|7|450560|0|ONLINE|
  1|SYSSMU1 1607784644$|5|3268608|0|ONLINE|
  2|SYSSMU2 3197760948$|5|3268608|0|ONLINE|
  3|SYSSMU3 2165878102$|7|5365760|0|ONLINE|
  . . .|. . .|. . .|. . .|. . .|. . .|
  - ' USN ' == Undo Segment ID
  - ' NAME ' = ' SYSTEM ' == Dictionary 테이블에 대한 변경 작업시 사용되는 Undo
  - ' EXTENTS ' == Undo Segment 內 Extent 수 ( Oracle Auto 관리 )
  - ' RSSIZE ' == Undo Segment 크기
  - ' XACTS ' == 진행중인 Transaction 수
  - ' STATUS ' == DB Open 時 ' ONLINE ' ( Oracle Auto )
    - ```SQL
      ALTER SYSTEM SET undo_tablespace = undotbs1 SCOPE=BOTH; /* 사용하는 Undo File 변경 */
      ```
      - 기존의 Undo Segment == ' OFFLINE ' 처리
      - Transaction 진행중에, Undo File 변경 時 ' STATUS ' == ' PENDING OFFLINE '
        - ' STATUS ' == ' PENDING OFFLINE ' 존재시, Undo Tablespace 삭제 불가
- ```SQL
  select s.username, s.sid, s.serial#, t.xidusn, t.ubafil, t.ubablk, t.used_ublk
  from v$session s, v$transaction t
  where s.saddr = t.ses_addr;
  ```
  > 현재 종료되지 않은, Transaction 정보 조회 예제 코드

  |USERNAME|SID|SERIAL#|XIDUSN|UBAFIL|UBABLK|USED_UBLK|
  :---|---:|---:|---:|---:|---:|---:|
  INSA|37|14956|5|4|1079|1|
  - ' UBABLK ' == Transaction 이전값이 저장된 Undo Block ID
  - ' USED_UBLK ' == 사용한 Undo Block 수
