# BMI 계산: 체중(kg) / (신장(m) ** 2)

18.5 <= bmi < 24.9 => 정상 체중
25 <= bmi < 29.9 => 과체중
bmi >= 29.9 => 비만 


# 함수 호출 사용 예시

height = 1.75  # 신장 (m)

# 결과 예시

윤년 규칙 
- 연도가 4로 나누어 떨어지면 윤년.

# print() 문안에 함수 호출 예시 
print(f' 2000 년도는 {is_leap_year(2000)}')
print(f' 2025 년도는 {is_leap_year(2000)}')
print(f' 2030 년도는 {is_leap_year(2000)}')

# 결과 예시 
 1988 년도는 윤년
 2000 년도는 윤년
 2025 년도는 평년
 2030 년도는 평년
