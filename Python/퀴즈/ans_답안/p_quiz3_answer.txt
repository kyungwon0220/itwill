수정, 추가, 삭제하여라 

초기 리스트 : ['사과', '바나나', '체리']
결과 1  : ['사과', '바나나', '체리', '오렌지', '포도']
결과 2  : ['사과', '복숭아', '수박', '오렌지', '포도']
결과 3  : ['사과', '복숭아', '오렌지', '포도']        
결과 4  : ['사과', '복숭아', '오렌지']
결과 5  : ['한라봉', '사과', '복숭아', '오렌지']  


# 초기 리스트
items_list = ["사과", "바나나", "체리"]

# "오렌지", "포도" 추가 

# 데이타 수정 : '바나나' → '복숭아', '체리' → '수박' 

# '수박' 삭제

# 리스트의 마지막 항목 제거

# 첫번째 위치에 '한라봉' 삽입 



# 초기 리스트
items_list = ["사과", "바나나", "체리"]
print(f'초기 리스트 : {items_list}')

# "오렌지", "포도" 추가 
items_list += ["오렌지", "포도"]
print(f'결과 1  : {items_list}')

# 데이타 수정 : '바나나' → '복숭아', '체리' → '수박'

# 리스트 정의 
word_list = [ 'apart', 'banana', 'orange', 'cherry' ]
print(f' step0 : word_list = {word_list} ')

# 비어있는 튜플 정의 
word_tuple = ()
print(f' step1 : word_tuple = {word_tuple} ')

# 리스트의 1번째 요소에서 첫글자와 마지막 글자로 구성된 데이타를 튜플에 삽입

# 리스트의 2번째 요소에서 홀수번째 글자로 구성된 데이타를 튜플에 삽입

# 리스트의 3번째 요소에서 짝수번째 글자로 구성된 데이타를 튜플에 삽입
