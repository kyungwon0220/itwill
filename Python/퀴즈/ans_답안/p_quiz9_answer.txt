4. 가변인자(*args)를 활용한 학생 성적 평균 계산 함수를 프로그래밍 하시오. 
- 학생 이름과 여러 개의 점수를 받아 평균을 계산하고 출력한다. 
- 점수 데이타가가 없는 경우 평균 대신 '점수가 없습니다.' 메세지 출력 
 
# 함수 호출 예시
print(calculate_average("김철수", 90, 85, 88, 92))  
print(calculate_average("박지민", 76, 81))  
print(calculate_average("이준호"))  # 점수 없이 호출


# 함수 호출 결과 예시

김철수의 평균 점수: 88.75
박지민의 평균 점수: 78.50
이준호의 점수가 없습니다.


# 정답 
def calculate_average(student_name, *scores):
    if not scores:
        return f"{student_name}의 점수가 없습니다."
    average = sum(scores) / len(scores)
    return f"{student_name}의 평균 점수: {average:.2f}"

# 함수 호출 결과 예시
print(calculate_average("김철수", 90, 85, 88, 92))  
print(calculate_average("박지민", 76, 81))  
print(calculate_average("이준호"))  # 점수 없이 호출

10. 특정범위의 알파벳 대문자나 소문자를 리스트 형태로 생성하는 함수를 정의하고 호출하여라 
- ord(), chr() 활용 


# 함수 호출 예시 
print(make_alphabet_list('x', 'z'))
print(make_alphabet_list('A', 'F'))


# 함수 호출 결과 예시 
['x', 'y', 'z']
['A', 'B', 'C', 'D', 'E', 'F']




# 정답 
def make_alphabet_list(start, end):
    char_list = [chr(i) for i in range(ord(start), ord(end) + 1)]
    return char_list
    
    
print(make_alphabet_list('x', 'z'))
print(make_alphabet_list('A', 'F'))
'''
['x', 'y', 'z']
['A', 'B', 'C', 'D', 'E', 'F']
'''
