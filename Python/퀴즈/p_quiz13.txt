09.   쇼핑몰에서 주문이 발생하면, '주문(Order)' 객체가 '상품(Product)'을 담고, 이를 '사용자(User)'에게 배송하는 과정을 클래스를 이용하여 구현하여라

[ Product 클래스]
상품 정보를 저장
상품명(name)
가격(price)

[ User 클래스]
사용자 정보를 저장
이름(name)
배송지(address)

[ Order 클래스]
하나의 주문 정보를 관리하는 클래스
생성자의 매개변수로 User 객체를 전달받는다.
주문한 상품들을 저장할 리스트(cart)를 생성한다

[ Order 클래스 구현 기능] 

- 상품 추가 기능
메서드명 : add_product()
Product 객체를 매개변수로 전달받는다.
전달받은 상품을 장바구니(cart)에 저장한다.
상품이 추가되었다는 메시지를 출력한다. (예 - '노트북'이(가) 장바구니에 담겼습니다.)


- 주문 기능
메서드명 : checkout()
주문 정보를 출력한다.
주문 상품의 총 금액을 계산하여 출력한다.
배송 시작 메시지를 출력한다.

예)

--- 주문서 ---
주문자: 드림
배송지: 서울시 서대문구 연희동
상품 목록: 노트북, 무선 마우스
총 결제 금액: 1530000원
배송이 시작되었습니다!



[ 프로그래밍 사용 예시 ]
user = User("서하늘", "서울시 서대문구 연희동")
order = Order(user)

order.add_product(Product("노트북", 1500000))
order.add_product(Product("무선 마우스", 30000))

order.checkout()



[ 프로그래밍 실행 결과 예시  ]
