### CTAS ( 테이블 복제 )
- TABLE 구조, 행(DATA), NOT NULL 제약 조건 복제
- TABLE 복제를 위해서도, TABLE 생성시와 같이 ' CREATE TABLE 시스템 권한 ', ' QUOTA 메모리 할당 ' 조건이 만족해야 한다
- 복제하는 컬럼중 표현식이 존재할시, 별칭 지정 필수 ( 복제하는 컬럼명에 ' | ' 특수 문자 사용 불가 )
```SQL
CREATE TABLE CTAS_EMP
TABLESPACE users
AS /* CTAS */
SELECT employee_id, last_name || ' ' || first_name AS name /* CTAS 內 SELECT 표현식에서는 별칭 필수 ( 별칭 지정 안할시 ERR 발생 ) */
FROM HR.EMPLOYEES;


CREATE TABLE CTAS_EMP2
TABLESPACE users
AS
SELECT *
FROM HR.EMPLOYEES
WHERE 1 = 2; /* 조건절을 FALSE 만들시, DATA 내용 없이 테이블의 구조 뼈대만 복제 */
```
> 앞글자 ' C T A S ' ( 씨타스 )
- 컬럼을 가공할 경우, 컬럼명 조건에 알맞게 별칭 지정 필수

### TCL(Transaction Control Language)
- COMMIT : 영구 저장
  - DDL, DCL 문은 정상 수행되면 Auto COMMIT 발생
    - SQLPLUS 환경에서 EXIT 종료시 Auto COMMIT 발생 ( 자동으로 COMMIT 후에 종료 )
    - SQLPLUS 환경상 트랜잭션 상황에서, CONN 다른 계정으로 접속시 Auto COMMIT 발생
- ROLLBACK : Transaction 시작된 절까지 포함하여, 작업 취소
  - SQLPLUS 환경상, 강제 종료시 자동 ROLLBACK 발생 ( 자동으로 ROLLBACK 후에 종료 )
- SAVEPOINT
  - 먼저 생성한 포인트로 ROLLBACK 하면, 이후 포인트로 이동 불가
    - 예를 들어, Point1 생성 후에, Point2 생성
    - Point1 지점으로 ROLLBACK
    - Point1 수행까지 적용, 이후 문장 모두 취소 ( Point2 이동 불가 )
