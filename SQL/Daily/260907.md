### CROSS JOIN ( Cartesian Product )
```SQL
SELECT e.employee_id, e.salary, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d; /* JOIN 생략시, Cartesian Product */


SELECT e.employee_id, e.salary, d.department_name
FROM HR.EMPLOYEES e
CROSS JOIN HR.DEPARTMENTS d; /* ANSI 표준 방식의 Cartesian 곱 발생 문법 */
```

### NATURAL JOIN
- 양쪽 테이블의, 같은명의 모든 컬럼을 기준으로 조인 조건 술어 처리 ( EQUI JOIN 처리 )
- NATURAL JOIN 처리된 컬럼은 테이블명을 명시하지 않고 사용 ( ANSI 표준 )
  - SELECT 절에서, ' * ' 전체 출력 사용 불가 ( 컬럼명들을 직접 타이핑 명시 필요 )
```SQL
SELECT d.department_name, l.city, location_id /* NATURAL JOIN 처리된 컬럼은, 테이블명을 붙일시 ERR */
FROM HR.DEPARTMENTS d, NATURAL JOIN HR.LOCATIONS l;


SELECT d.department_name, l.* /* NATURAL JOIN 처리된 컬럼이 존재하여, ' * ' 전체 출력 불가 */
FROM HR.DEPARTMENTS d, NATURAL JOIN HR.LOCATIONS l;
```

### JOIN USING
- USING 절에서 명시한 컬럼들을 기준으로 JOIN 조건 술어 처리
- USING 절에서 명시한 컬럼들은, 테이블명 기재시 ERR 발생
```SQL
SELECT e.employee_id, l.city, department_id /* USING 절에서 기준으로 사용한 컬럼명은 테이블명 없이 사용 ( ' d.department_id ' 식으로, 테이블명 지정시 ERR 발생 ) */
FROM hr.employees e JOIN hr.departments d
USING (department_id)
JOIN hr.locations l /* 상위 JOIN 결과 집합으로, hr.locations 테이블 JOIN */
USING (location_id)
WHERE department_id IN(20, 30, 50); /* USING 절에서 기준으로 사용한 컬럼명은, 테이블명 없이 사용 */
```

### Nested Subquery ( 중첩 서브 쿼리 )
- ' Subquery ' == SQL 문장 안에, 다른 SQL 
- 소괄호로 묶어 사용
- Subquery 먼저 수행하고, 결과를 Main(Outer) 쿼리절에서 사용
- 단일행 비교 연산자 ( =, >, >=, <, <=, <>, !=, ^= ) 사용시에는, Subquery 결과가 단일행 필요 ( 여러 행의 Subquery 결과가 나오는 경우, 비교가 불가하여 ERR 발생 )
- 여러 행을 비교하는 연산자 : IN, ANY, ALL
```SQL
SELECT *
FROM HR.EMPLOYEES
--WHERE salary > (SELECT salary
--                FROM HR.EMPLOYEES
--                WHERE last_name = 'King'); /* Subquery 결과가, 단일행이 아니어서 비교가 불가하여 ERR 발생 */
WHERE salary > (SELECT MAX(salary) /* Subquery 결과 단일행 */
                FROM HR.EMPLOYEES
                WHERE last_name = 'King');
```

### Correlate Subquery ( 상호 관련 서브 쿼리 ), EXISTS()
- Main 쿼리절상의 테이블명이 Subquery 內 존재
```SQL
SELECT *
FROM HR.EMPLOYEES o /* Main 쿼리절의 테이블에 별칭 지정 */
WHERE salary > (SELECT AVG(salary)
                FROM HR.EMPLOYEES
                WHERE department_id = o.department_id); /* o.department_id == 후보행 */
```
1. Subquery 內 ' o.department_id ' 후보행의 값은 미지수이기에, 이를 알고있는 Main(Outer) 쿼리절이 먼저 수행 ( FULL SCAN )
2. ' 첫행을 후보행으로 잡고, 이를 Subquery 미지수에게로 전달 ( 'o.department_id ' == 첫행의 ' department_id ' )
3. 전달받은 ' department_id ' 값을 갖고 Subquery 수행하고, WHERE 절을 수행 ( 전달받은 department_id 부서의 salary 평균값과( Subquery 결과 ), 후보행의 salary 비교 )
4. 비교값이 TRUE 경우, 결과 집합에 ( 메모리 ) 저장
5. 다음 둘번 행을 후보행으로 잡고, Main 쿼리 행의 수만큼 반복
- Main 쿼리절 행의 수만큼 반복하는 부담 존재
- 같은 후보행 값이어도, ( department_id ) 반복하는 문제 존재
</br></br></br>
```SQL
SELECT *
FROM HR.DEPARTMENTS
WHERE department_id IN (SELECT department_id
                        FROM HR.EMPLOYEES);


SELECT *
FROM HR.DEPARTMENTS o
WHERE EXISTS (SELECT NULL /* 문법 오류 방지 위해, SELECT 문 작성 ( 의미없는 문자나 숫자 가능 )*/
                FROM HR.EMPLOYEES
                WHERE department_id = o.department_id);
```
| 두 코드는, 같다
- EXISTS() : Subquery WHERE 절 수행중, 조건을 만족하는 행이 존재시 TRUE 반환 ( 검색 종료 )
  - 존재하는 행을 찾았다면, 추가 존재 여부를 확인할 필요가 없기에 추가 탐색 중단

### INLINE VIEW ( 가상 테이블 )
- FROM 절에 소괄호로 작성
```SQL
SELECT e1.*, e2.*
FROM (SELECT department_id, ROUND(AVG(salary), 2) AS "부서별 급여 평균" /* INLINE VIEW */
        FROM HR.EMPLOYEES
        GROUP BY department_id) e1,
    HR.EMPLOYEES e2
WHERE e1.department_id = e2.department_id AND e1."부서별 급여 평균" < e2.salary
ORDER BY e2.salary DESC;


SELECT e1.*, e2.*
FROM (SELECT department_id, ROUND(AVG(salary), 2) AS "부서별 급여 평균" /* INLINE VIEW */
        FROM HR.EMPLOYEES
        GROUP BY department_id) e1
JOIN HR.EMPLOYEES e2 /* ANSI 표준 방식 문법 */
ON e1.department_id = e2.department_id
WHERE e2.salary > e1."부서별 급여 평균"
ORDER BY e2.salary DESC;
```
