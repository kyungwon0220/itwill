```SQL
SELECT last_name
FROM HR.EMPLOYEES
WHERE last_name NOT BETWEEN 'Ac' AND 'Ax' /* 알파벳도 사전식 기준으로 문자열 비교하여 범위를 판단 */
ORDER BY last_name;
```
- where last_name not between 'Ac' and 'Ax'
  - last_name 값이, ' Ac ' 문자열로 시작하며, ' Ax ' 문자열로 시작하는 last_name 가진 행을 제외

```SQL
SELECT * FROM HR.EMPLOYEES
WHERE last_name LIKE 'HR^_^%%' ESCAPE'^';
```
- ESCAPE 키워드로 지정한 ' ^ ' 문자의, 다음에 오는 ' _ ' 특수문자를, ' _ ' 문자 자체로 인식 ( 어떠한 한글자를 뜻하는 언더바가 아닌, ' _ ' 문자 자체로 인식 )
