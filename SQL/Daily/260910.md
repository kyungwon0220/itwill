### 계층 검색(Hierarchical Query)
- 테이블 內 트리 구조 데이터 조회 ( 조직도, 쇼핑몰 카테고리, 부품 구조 등에서 활용 )
- START WITH 문은 필수가 아니나, CONNECT BY 구문은 필수
```SQL
SELECT employee_id, last_name, manager_id
FROM HR.EMPLOYEES
START WITH employee_id = 100 /* 시작점 ( root ) */
CONNECT BY PRIOR employee_id = manager_id; /* 연결 고리 조건 */


SELECT employee_id, last_name, manager_id
FROM HR.EMPLOYEES
START WITH employee_id = 101 /* 시작점 ( root ) */
CONNECT BY employee_id = PRIOR manager_id; /* PRIOR 지정 위치에 따라, 아래에서 위로로 탐색 순서가 달리진다 */
```

### ORDER BY
#### ORDER SIBLINGS BY
- 같은 LEVEL ( TREE 층수 ) 내에서의 정렬
- SIBLINGS 옵션 사용시, 컬럼의 별칭이나 위치 표기법 사용 불가
```SQL
SELECT LEVEL, LPAD(' ', LEVEL * 2, ' ') || last_name AS name
FROM HR.EMPLOYEES e
START WITH employee_id = 101 /* 시작점 ( root ) */
CONNECT BY PRIOR employee_id = manager_id
ORDER SIBLINGS BY last_name DESC; /* SIBLINGS == 같은 LEVEL 안에서 정렬 */
```

### SYS_CONNECT_BY_PATH()
- 계층 검색에서 사용되는 함수
- 둘번 인자에는, PATH 부호를 입력 ( ' / ' 슬래쉬말고 다른 구분 문자열도 사용 가능 )
```SQL
SELECT LEVEL,
        LPAD(' ', LEVEL * 2, ' ') || last_name AS name,
        SYS_CONNECT_BY_PATH(last_name, '/') path
FROM HR.EMPLOYEES e
START WITH employee_id = 101 /* 시작점 ( root ) */
CONNECT BY PRIOR employee_id = manager_id
ORDER SIBLINGS BY last_name; /* SIBLINGS == 같은 LEVEL 안에서 */
```
