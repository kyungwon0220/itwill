### GROUP BY
- 9i R1 Version 까지는, SORT GROUP BY 수행으로 정렬된 결과 출력
- 9i R2 VERSION 부터는, HASH GROUP BY 수행으로 정렬없이 결과 출력
- SELECT 절 內 그룹 함수내에 들어있지 않은, 일반 개별 컬럼들은 반드시 GROUP BY 절에 명시
- GROUP BY 절에서는, 열의 별칭이나 위치 표기법 사용 불가
```SQL
SELECT department_id, job_id, sum(salary)
FROM HR.EMPLOYEES
GROUP BY department_id, job_id; /* SELECT 절 內 그룹 함수내에 들어있지 않은, 일반 개별 컬럼들 */
```
```SQL
select department_id as "dept", sum(salary), count(*)
from hr.employees
group by department_id /* ' 1 ', ' dept ' 식으로, 열의 별칭이나 위치 표기법 사용 불가 */
order by 3 desc;
```
```SQL
SELECT department_id, MAX(AVG(salary)) /* ' MAX(AVG(salary)) ' 결과는 하나의 행이고 일반 개별 컬럼의, 결과 행의 개수와 맞지 않다 */
FROM HR.EMPLOYEES
GROUP BY department_id;
```
| ORA-00937 ERR 발생 예제 코드
```SQL
SELECT department_id, AVG(salary) /* 그룹화한 부서별의, salary 평균 */
FROM HR.EMPLOYEES
GROUP BY department_id /* ' department_id ' 부서별로 그룹화 */
HAVING AVG(salary) = (SELECT MAX(AVG(salary)) /* 서브 쿼리 */
                      FROM HR.EMPLOYEES 
                      GROUP BY department_id);
```
| 서브 쿼리로, 분리 작성하여 ERR 해결

### HAVING
- GROUP BY 절로 그룹화한, 최종 결과 행에 대한 조건
```SQL
SELECT department_id, sum(salary)
FROM HR.EMPLOYEES
GROUP BY department_id
HAVING COUNT(*) >= 5; /* SELECT 절에 없는, 조건으로도 제한 가능 */
```
| 부서별 합계 최종 결과에서, 5명 이상인 부서만 출력 조건

### EQUI JOIN
- ' = ' 연산자로 JOIN 방식
- JOIN 조인 조건 술어는, 테이블의 개수 - 1 개 작성 필요 ( 3개의 테이블을 조인시, 2개의 조건 술어 필요 )
```SQL
SELECT HR.EMPLOYEES.employee_id, HR.EMPLOYEES.last_name, HR.DEPARTMENTS.department_name
FROM HR.EMPLOYEES, HR.DEPARTMENTS
WHERE HR.EMPLOYEES.department_id = HR.DEPARTMENTS.department_id; /* Oracle 전통 옛방식 JOIN 문법 */


SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d /* 테이블명 별칭 사용 가능 */
WHERE e.department_id = d.department_id; /* Oracle 전통 옛방식 JOIN 문법 */
```
```SQL
SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d
WHERE HR.EMPLOYEES.department_id = HR.DEPARTMENTS.department_id; /* ' e '. ' d ' 같이, 테이블에 별칭을 선언하고 사용하지 않으면 ERR 발생 */
```
| 테이블 별칭 선언하고, 사용하지 않는 경우 ERR 발생 예제 코드

</br></br></br>

```SQL
SELECT last_name, city
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d, HR.LOCATIONS l
WHERE e.department_id = d.department_id AND d.location_id = l.location_id /* JOIN 조건 술어 */
ORDER BY city DESC;
```
| 3개의 테이블을 JOIN ( 2개의 JOIN 조건 술어 작성 )
```SQL
SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e
JOIN HR.DEPARTMENTS d
ON e.department_id = d.department_id; /* ANSI 표준 방식 JOIN 문법 */


SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e
INNER JOIN HR.DEPARTMENTS d
ON e.department_id = d.department_id;
```
| ANSI == American National Standards Institue)
| 두 코드는, 같다 ( ' INNER ' 키워드 디폴트로, 생략 가능 )

### NON EQUI JOIN ( 비등가 JOIN )
- 범위 조건으로 관계를 찾는, EQUI 외의 비교 연산자 ( >, >=, <, <=, !=, <> ) 사용
```SQL
SELECT e.employee_id, e.salary, j.grade_level
FROM HR.EMPLOYEES e, HR.JOB_GRADES j
-- WHERE e.salary >= j.lowest_sal AND e.salary <= j.highest_sal;
WHERE e.salary BETWEEN j.lowest_sal AND j.highest_sal


SELECT e.employee_id, e.salary, j.grade_level
FROM HR.EMPLOYEES e
JOIN HR.JOB_GRADES j /* ANSI 표준 방식 JOIN 문법 */
ON e.salary BETWEEN j.lowest_sal AND j.highest_sal;
```

### OUTER JOIN ( RIGHT OUTER JOIN, LEFT OUTER JOIN )
- JOIN 조건 술어에서, 양쪽의 테이블에 ' (+) ' 붙이는 경우, ERR 발생
  - ANSI 표준 방식의 문법으로는 ' FULL OUTER JOIN ' 가능
```SQL
SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d
WHERE e.department_id(+) = d.department_id; /* JOIN 조건 술어에서 ' (+) ' 안붙은, hr.departments 테이블 기준으로(모든 부서명 출력) RIGHT OUTER JOIN */


SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e
RIGHT OUTER JOIN HR.DEPARTMENTS d /* == ' WHERE e.department_id(+) = d.department_id '*/
ON e.department_id = d.department_id; /* ANSI 표준 방식 JOIN 문법 */


SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d
WHERE e.department_id = d.department_id(+); /* JOIN 조건 술어에서 ' (+) ' 안붙은, hr.employee 테이블 기준으로(모든 사원 출력) LEFT OUTER JOIN */


SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d
LEFT OUTER JOIN HR.DEPARTMENTS d /* == ' WHERE e.department_id = d.department_id(+) '*/
ON e.department_id = d.department_id; /* ANSI 표준 방식 JOIN 문법 */
```
```SQL
SELECT e.employee_id, e.last_name, d.department_name
FROM HR.EMPLOYEES e
FULL OUTER JOIN HR.DEPARTMENTS d /* ANSI 표준 방식의 문법으로만, ' FULL OUTER JOIN ' 사용 가능 */
ON e.department_id = d.department_id;
```
```SQL
SELECT employee_id, last_name, department_name
FROM HR.EMPLOYEES e, HR.DEPARTMENTS d
WHERE e.department_id(+) = d.department_id(+); /* 양쪽에 ' (+) ' 부호 붙이는 경우, ERR 발생 */
```
| 양쪽에 ' (+) ' 부호 붙이는 경우, ERR 발생 예제 코드 ( 필요시, ' FULL OUTER JOIN ' 사용 )

### SELF JOIN
```SQL
SELECT w.employee_id, w.last_name, m.employee_id, m.last_name
FROM HR.EMPLOYEES w, HR.EMPLOYEES m /* 같은 테이블을, 별칭으로 구분 */
WHERE w.manager_id = m.employee_id; /* SELF JOIN */


SELECT w.employee_id, w.last_name, m.employee_id, m.last_name
FROM HR.EMPLOYEES w
JOIN HR.EMPLOYEES m /* ANSI 표준 방식 JOIN 문법 */
ON w.manager_id = m.employee_id;
```
| manager_id == NULL 최상위 관리자는, 결과에서 제외되는 예제 코드 ( 출력 필요시, OUTTER JOIN 사용 )
