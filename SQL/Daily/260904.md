### GROUP BY
- 9i R1 Version 까지는, SORT GROUP BY 수행으로 정렬된 결과 출력
- 9i R2 VERSION 부터는, HASH GROUP BY 수행으로 정렬없이 결과 출력
- SELECT 절 內 그룹 함수내에 들어있지 않은, 일반 개별 컬럼들은 반드시 GROUP BY 절에 명시
- GROUP BY 절에서는, 열의 별칭이나 위치 표기법 사용 불가
- SELECT 內 그룹 함수를 중첩으로 사용시, 일반 개별 컬럼이 존재하면 ERR 발생
```SQL
SELECT department_id, job_id, sum(salary)
FROM HR.EMPLOYEES
GROUP BY department_id, job_id; /* SELECT 절 內 그룹 함수내에 들어있지 않은, 일반 개별 컬럼들 */
```
```SQL
select department_id as "dept", sum(salary), count(*)
from hr.employees
group by department_id /* ' 1 ', ' dept ' 식으로, 열의 별칭이나 위치 표기법 사용 불가 */
order by 3 desc;
```
```SQL
SELECT department_id, MAX(AVG(salary)) /* ' MAX(AVG(salary)) ' 결과는 하나의 행이고 일반 개별 컬럼의, 결과 행의 개수와 맞지 않다 */
FROM HR.EMPLOYEES
GROUP BY department_id;
```
| ORA-00937 ERR 발생 예제 코드
```SQL
SELECT department_id, AVG(salary) /* 그룹화한 부서별의, salary 평균 */
FROM HR.EMPLOYEES
GROUP BY department_id /* ' department_id ' 부서별로 그룹화 */
HAVING AVG(salary) = (SELECT MAX(AVG(salary)) /* 서브 쿼리 */
                      FROM HR.EMPLOYEES 
                      GROUP BY department_id);
```
| 서브 쿼리로, 분리 작성하여 ERR 해결

### HAVING
- GROUP BY 절로 그룹화한, 최종 결과 행에 대한 조건
```SQL
SELECT department_id, sum(salary)
FROM HR.EMPLOYEES
GROUP BY department_id
HAVING COUNT(*) >= 5; /* SELECT 절에 없는, 조건으로도 제한 가능 */
```
| 부서별 합계 최종 결과에서, 5명 이상인 부서만 출력 조건
