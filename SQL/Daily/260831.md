## 260831mon
```SQL
SELECT salary * 12 연봉, ' 사번 : ' || employee_id || q'[. TestText]' AS "사번 + TESTTEXT"
FROM HR.EMPLOYEES;
```
- SELECT 절에서 ' * 12 ' 같은 계산 가능<br>
- ' AS " A B C " == ABC 라는 별칭 지정 ( ' AS ' 키워드 생략 가능 )
- 문자열은 왼쪽 정렬, NUMBER 타입은 우측 정렬로 결과가 출력ㄷ
- ` q'[]' ` Oracle의 Q-quoted string 문법
