### NVL(), NVL2(), COALESCE()
```SQL
SELECT
    NVL(to_char(commission_pct), 'no comm'), /* NVL(x, y) == x, y 데이터 타입이 일치해야 한다 */
    NVL2(commission_pct, salary, salary * 12), /* NVL2(x, y, z) == y, z 데이터 타입이 일치해야 한다 */
    COALESCE(commission_pct, NULL, NULL, NULL), /* 인자 개수 제한이 없고, 모두 NULL 이라면 NULL 반환 */
    NULLIF(commission_pct, NULL)
FROM HR.EMPLOYEES;
```
- NVL(x, y) == ' x ' NULL 일시, y 값으로 대체
- NVL2(x, y, z) == ' x ' NULL 아닐시 y, NULL 일시에는 z 값으로 대체
- COALESCE(x, y, z, . . .) == ' x ' NULL 일시, y. NULL 일시 z, . . . NULL 아닌 값을 반환

### DECODE()
```SQL
SELECT salary,
    DECODE(job_id,
        'AC_ACCOUNT', salary, /* job_id == AC_ACCOUNT 라면, salary 반환 */
        'AC_MGR', salary * 0, /* job_id == AC_MGR 라면, salary * 0 반환 */
        NULL) AS DECODE /* job_id 비교값이 없을 경우, 마지막 인자인 ' NULL ' 반환 */
FROM HR.EMPLOYEES
ORDER BY job_id;
```

### CASE

SELECT salary,

### 그룹 함수
- 여러 행당, 하나의 결과를 반환하는 함수
- SUM(), MEDIAN(), VARIANCE(), STDDEV(), MAX(), MIN(), COUNT()
  - 모든 데이터 타입 사용 가능한 함수 : MAX(), MIN(), COUNT()
- 그룹 함수는 NULL 행을 제외하고 계산
  - 단, ' COUNT(*) ' 경우에만, NULL 포함한 전체 행수를 반환 ( COUNT(x) == NULL 제외한, x 개수 반환 )
```SQL
SELECT
    COUNT(*),
    COUNT(commission_pct), /* ' NULL ' 가진 개수를 제외한 35 출력 */
    COUNT(department_id), /* ' NULL ' 가진 개수를 제외한 106 출력 */
    COUNT(DISTINCT department_id), /* 중복을 제외한 건수 출력 */
    COUNT(UNIQUE department_id), /* 중복을 제외한 건수 출력 */
    SUM(commission_pct), /* NULL 제외한 나머지 행들의 합 */
    MEDIAN(salary), /* 중앙 값 */
    AVG(salary), /* NULL 제외한, 나머지 행들의 평균 */
    VARIANCE(salary), /* 숫자 데이터의 분산 */
    STDDEV(salary), /* 표준 편차 */
FROM HR.EMPLOYEES;
```

### DISTINCT, UNIQUE 키워드 ( 중복 제외 )
- SELECT 절에서는 DISTINCT, UNIQUE 두개의 키워드는 동일하게 중복을 제거한다는 의미로 사용된다
- 차후 공부할, CREATE TABLE 절에서 사용하는 UNIQUE == 중복 데이터 저장을 방지하는 키워드로 사용된다
