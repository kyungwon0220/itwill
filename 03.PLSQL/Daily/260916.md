### 변수
- 변수명은 문자로 시작해야 한다 ( 문자, 숫자, 특수문자 ( _, #, $ ) 포함 가능 )
- 변수명의 길이는 30자 이하로 가능
- 변수명으로, 예약어는 사용 불가
  - ' SELECT * FROM v$reserved_words WHERE reserved = 'Y'; ' 실행 결과 == 사용 불가
- 변수 선언시 NOT NULL, CONSTANT ( 상수 ) 경우, 초기값 (기본값) 설정 (할당) 필수
  - ```SQL
    DECLARE
      name VARCHAR2(30); /* ' name ' == 디폴트 값인 NULL */
      job VARCHAR2(50) NOT NULL := 'Oracle DBA'; /* NOT NULL 존재시, 기본값 할당 필수 */
      day CONSTANT DATE DEFAULT SYSDATE; /* CONSTANT ( 상수 ) 선언시, 기본값 할당 필수 */
    BEGIN
    END;
    /
    ```
    - SQL DEVELOPER 프로그램 上 VARCHAR2 타입은 ' (20) ' 같이, 사이즈 미지정시 ERR

#### 바인드 변수 ( Bind Variable ) == 호스트 변수 ( HOST Variable )
```SQL
SELECT *
FROM HR.EMPLOYEES
WHERE employee_id = :id; /* 선언없이 바로 사용 ( 명령문 실행하면, 바인드 변수값 입력창 ) */
```
> SQL DEVELOPER 프로그램상, 바인드 변수 사용 예제 코드

</br></br></br>
```SQL
VAR id NUMBER /* 선언 ( SQL DEVELOPER 프로그램상에서는 선언 불필요 )*/
--VAR id NUMBER(2) /* SQL PLUS 환경 上 NUMBER 타입은 ' (2) ' 같이, 사이즈 지정 불가 ERR */


EXECUTE :id := 110 /* 할당 */


PRINT id /* DBMS 출력 */
PRINT :id /* DBMS 출력 */


> SELECT employee_id
  2  FROM HR.EMPLOYEES
  3  WHERE employee_id = :id; /* 활용 */
```
> CMD 上 SQL PLUS 환경에서, 바인드 변수를 선언하고 할당하여 출력하는 예제 코드
- SQL PLUS 환경 上 NUMBER 타입은 ' (2) ' 같이, 사이즈 지정 불가 ERR
- SQL PLUS 환경 上 바인드 변수로 DATE 타입 사용 불가
